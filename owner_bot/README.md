Telegram-бот для владельца магазина: приём товаров, управление каталогом, загрузка фото.

**Бот:** [@tophitboss_bot](https://t.me/tophitboss_bot) — "Управляющий магазина"

## Приход товара

### Быстрый ввод

Введите данные одним сообщением:

```
Название Цена Количество
```

Примеры:
- `Махорка СССР 500 10` → название, цена 500₽, 10 шт.
- `Кофе Арабика 1200р 25шт` → с суффиксами

### Процесс

```
1. Ввод данных
   └─ Быстрая строка или пошаговый ввод

2. Поиск похожих товаров
   └─ Выбрать существующий или создать новый

3. Фото товара
   ├─ Загрузить новое
   ├─ Оставить текущее
   └─ Пропустить

4. Анализ качества фото
   ├─ Принять
   ├─ Улучшить (денойзинг, обрезка)
   └─ Переснять

5. Подтверждение
   └─ Запись в Google Sheets + загрузка в Drive
```

## Просмотр склада

Кнопка **📊 Склад** открывает постраничный список всех товаров:
- 8 товаров на страницу
- Сортировка: активные вверху, затем по названию
- Статистика: количество активных, общий остаток
- Клик по товару → карточка с действиями

## Операции с товарами

При выборе товара (из поиска или списка склада) доступны следующие действия:

| Кнопка | Действие |
|--------|----------|
| 📦 Приход | Добавить количество к остатку |
| ➖ Списать | Уменьшить остаток с указанием причины |
| 🧮 Корректировка | Установить фактический остаток |
| 📷 Фото | Заменить фотографию товара |
| 🗑️ Архив | Деактивировать товар (с опцией обнуления) |

### Списание

Причины списания:
- 🗑️ Порча — испорченный товар
- 🎁 Подарок — отдан в подарок
- 🔄 Пересорт — пересортировка
- 📝 Другое — своя причина

Можно указать причину сразу: `5 порча` — списать 5 шт. по причине "порча".

### Корректировка

Причины корректировки:
- 📋 Инвентаризация — по результатам пересчёта
- 🔄 Пересорт — пересортировка товаров
- ⚠️ Ошибки учёта — исправление ошибок
- 📝 Другое — своя причина

### Архивация

Два режима:
1. **Архивировать** — скрыть из каталога, остаток не меняется
2. **Обнулить и архивировать** — списать оставшийся остаток и скрыть

## Установка

### Локально

```bash
cd owner_bot
cp .env.example .env
# Заполните .env

# Установка зависимостей
uv venv && source .venv/bin/activate
uv pip install -e .

# Запуск
python -m app.main
```

### Docker

```bash
cd owner_bot
cp .env.example .env
# Заполните .env

# Создайте папку secrets в корне проекта (если не создана)
mkdir -p ../secrets
cp /path/to/your-service-account.json ../secrets/

docker compose up --build
```

#### Docker Volumes

```yaml
services:
  owner-bot:
    volumes:
      - ./tmp:/app/tmp           # Временные файлы (фото)
      - ./data:/app/data         # Постоянные данные
      - ../secrets:/app/secrets  # Google Service Account JSON
```

| Volume | Хост | Контейнер | Назначение |
|--------|------|-----------|------------|
| tmp | `./tmp` | `/app/tmp` | Временные файлы (автоочистка) |
| data | `./data` | `/app/data` | Персистентные данные |
| secrets | `../secrets` | `/app/secrets` | Google credentials |

**Важно:** Путь к credentials в `.env` должен быть контейнерным:
```bash
# Правильно (внутри контейнера)
GOOGLE_SERVICE_ACCOUNT_JSON_PATH=/app/secrets/your-service-account.json

# Неправильно (локальный путь)
# GOOGLE_SERVICE_ACCOUNT_JSON_PATH=/Users/me/project/secrets/...
```

## Google Sheets — Структура (v1.1)

### Лист "Склад"

Основной лист с товарами (русские названия колонок):

| Колонка | Обязательно | Описание |
|---------|-------------|----------|
| SKU | Да | Уникальный идентификатор товара |
| Наименование | Да | Название товара |
| Цена_руб | Да | Цена в рублях |
| Стартовый_остаток | Да | Начальный остаток при создании |
| Внесено_всего | Авто | Формула SUMIF из листа Внесение |
| Списано_всего | Авто | Формула SUMIF из листа Списание |
| Остаток_расчет | Авто | Формула: Старт + Внесено - Списано |
| Фото_URL | Да | URL фотографии |
| Активен | Да | TRUE/FALSE (чекбокс) |
| Теги | Нет | Теги через запятую |
| Описание_кратко | Нет | Краткое описание |

### Листы "Внесение" и "Списание"

**Структура с двухстрочными заголовками:**
- **Row 1:** Английские заголовки (для кода)
- **Row 2:** Русские описания (для пользователей)
- **Row 3+:** Данные

**Колонки (LOG_COLUMNS):**

| # | Заголовок | Русское описание | Тип |
|---|-----------|------------------|-----|
| A | date | Дата | ISO datetime |
| B | operation_id | ID операции | string (UUID) |
| C | sku | Артикул | string |
| D | name | Название | string |
| E | qty | Количество | number |
| F | stock_before | Было на складе | number |
| G | stock_after | Стало на складе | number |
| H | reason | Причина | string |
| I | source | Источник | string |
| J | actor_id | ID актора | number |
| K | actor_username | Имя актора | string |
| L | note | Примечание | string |

**Self-heal:** Листы и колонки создаются автоматически при первой записи.

### Матрица операций и логирования

| Операция | Лист "Внесение" | Лист "Списание" | Колонка |
|----------|-----------------|-----------------|---------|
| Создание нового товара | ✅ `new_product` | - | `Внесено_всего` |
| Приход для существующего | ✅ `intake` | - | `Внесено_всего` |
| Корректировка (delta > 0) | ✅ `correction:*` | - | `Внесено_всего` |
| Корректировка (delta < 0) | - | ✅ `correction:*` | `Списано_всего` |
| Списание | - | ✅ причина | `Списано_всего` |
| Архивация с обнулением | - | ✅ `archive:zero_out` | `Списано_всего` |

### Поддерживаемые алиасы колонок

| Код использует | Также принимает |
|----------------|-----------------|
| Цена | Цена_руб |
| Остаток | Остаток_расчет |

## Безопасность

- **Whitelist** — доступ только по Telegram ID из `OWNER_TELEGRAM_IDS`
- **Подтверждения** — опасные действия требуют повторного нажатия (TTL 5 мин)
- **Никаких secrets в коде** — только env переменные

## Мониторинг

### Sentry (отслеживание ошибок)

Бесплатный план: 10,000 events/month.

1. Создайте аккаунт на [sentry.io](https://sentry.io)
2. Создайте Python проект
3. Скопируйте DSN в `.env`:

```bash
SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx
ENVIRONMENT=production  # или staging, development
```

### Telegram алерты

Критические ошибки отправляются всем владельцам из `OWNER_TELEGRAM_IDS`.

Использование в коде:
```python
from app.monitoring import alert_owner
await alert_owner(bot, "Ошибка подключения к Google Sheets!")
```

### Retry логика

Google API вызовы автоматически повторяются при сбоях (3 попытки с экспоненциальным backoff).

Использование:
```python
from app.monitoring import google_api_retry

@google_api_retry
async def my_sheets_operation():
    ...
```

### Docker Healthcheck

Проверяет реальное подключение к Google Sheets каждые 60 секунд:

```bash
docker inspect --format='{{.State.Health.Status}}' owner-bot
# healthy / unhealthy
```

## Производительность

### TTL-кэш товаров (Phase 3.1, 2026-01-31)

`ProductService` кэширует список товаров для быстрого поиска:
- TTL: 5 минут (настраивается)
- Автоматическая инвалидация при изменении товара
- Снижает нагрузку на Google Sheets API
- Добавлен в v1.5

### SQLite persistence

Intake sessions хранятся в SQLite для защиты от потери данных:
- TTL: 24 часа
- Восстановление сессий после перезапуска бота
- Автоматическая очистка устаревших записей
