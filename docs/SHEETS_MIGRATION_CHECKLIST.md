- [ ] **Цена_руб**: Убрать "₽" из значений

  - Ctrl+H: ` ` (неразрывный пробел \xa0) → (пусто)
  - Формат → Число → Валюта (RUB)

- [ ] **Активен**: Заменить "да"/"TRUE" на чекбоксы
  - Выделить колонку N (Активен)
  - Ctrl+H: `да` → `TRUE`
  - Ctrl+H: `нет` → `FALSE`
  - Данные → Проверка данных → Чекбокс

- [ ] **Пустые числа**: Заменить на 0
  - `Стартовый_остаток`: пустые → 0
  - `Внесено_всего`: пустые → 0
  - `Списано_всего`: пустые → 0


- [ ] В K2 ввести формулу:

- [ ] Протянуть формулы J2:K2 вниз на все строки с данными

- [ ] Формат → Условное форматирование:
