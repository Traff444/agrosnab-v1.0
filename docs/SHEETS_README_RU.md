## 📦 Лист "Склад" — Ваши товары

**Что это:** Главный список всех товаров магазина.

| Колонка | Что писать | Пример | Кто заполняет |
|---------|-----------|--------|---------------|
| **SKU** | Уникальный код товара. НЕ МЕНЯТЬ после создания! | `PRD-001` | Бот или вы |
| **Наименование** | Название товара для покупателей | `Махорка СССР` | Бот или вы |
| **Описание_кратко** | Короткое описание (1-2 предложения) | `Собрана в традициях СССР` | Вы |
| **Описание_полное** | Полное описание товара | `Премиальное качество...` | Вы |
| **Цена_руб** | Цена в рублях (ТОЛЬКО ЧИСЛО, без ₽) | `1000` | Бот или вы |
| **Стартовый_остаток** | Сколько было при создании товара | `50` | Бот |
| **Внесено_всего** | Сколько всего пришло (формула) | `20` | Автоматически |
| **Списано_всего** | Сколько всего ушло (формула) | `5` | Автоматически |
| **Остаток_расчет** | Текущий остаток (формула) | `65` | Автоматически |
| **Остаток_по_логам** | Проверка остатка (формула) | `65` | Автоматически |
| **Дельта** | Разница (должна быть 0!) | `0` | Автоматически |
| **Поставщик_ID** | Код поставщика из листа "Поставщик" | `SUP-001` | Вы |
| **Фото_URL** | Ссылка на фото товара | `https://...` | Бот |
| **Активен** | Показывать ли товар покупателям | ☑️ | Вы или бот |
| **Теги** | Категории через запятую | `золотая, крепкая` | Вы |

### ⚠️ Важно про "Склад"

- **SKU нельзя менять** — это ключ для заказов и списаний
- **Цена — только число** — пишите `1000`, а не `1 000 ₽`
- **Активен — чекбокс** — ставьте галочку, не пишите "да"
- **Дельта должна быть 0** — если не 0, значит где-то ошибка

### 🎨 Цветовая индикация

| Цвет | Что значит |
|------|------------|
| 🟡 Жёлтый фон в "Остаток_расчет" | Критический остаток (< 5 шт) — пора заказывать |
| 🔴 Красный фон в "Остаток_расчет" | Нет в наличии (0 шт) |
| 🔴 Красный фон в "Дельта" | Ошибка! Остаток не сходится с логами |
| ⬜ Серый текст | Товар неактивен (архив) |

## ➕ Лист "Внесение" — Приход товара

**Что это:** Журнал всех поступлений товара. Каждая строка = одна операция прихода.

### Структура листа

| Строка | Содержимое |
|--------|------------|
| **Строка 1** | Технические заголовки (английские, для бота) |
| **Строка 2** | Русские подписи колонок (для вас) |
| **Строка 3+** | Данные операций |

### Колонки

| Колонка | Русская подпись | Что это | Пример |
|---------|-----------------|---------|--------|
| A | Дата | Дата и время операции | `2026-01-30T14:25:00` |
| B | ID операции | Уникальный ID (защита от дублей) | `abc123def456` |
| C | Артикул | Код товара | `PRD-001` |
| D | Название | Название товара | `Махорка СССР` |
| E | Количество | Количество прихода | `10` |
| F | Было на складе | Остаток ДО операции | `50` |
| G | Стало на складе | Остаток ПОСЛЕ операции | `60` |
| H | Причина | `intake`, `correction` | `intake` |
| I | Источник | Откуда: `owner_intake` | `owner_intake` |
| J | ID актора | Telegram ID | `481890` |
| K | Имя актора | Username | `admin` |
| L | Примечание | Комментарий | `Приход от поставщика` |

### ⚠️ Важно про "Внесение"

- **НЕ редактируйте этот лист вручную** — только бот пишет сюда
- **НЕ удаляйте строку 2** — это русские подписи для удобства
- Это журнал (лог) — данные только добавляются, не меняются
- Если нужно исправить ошибку — делайте корректировку через бот

## ➖ Лист "Списание" — Расход товара

**Что это:** Журнал всех списаний товара (продажи, порча, подарки).

### Структура листа

| Строка | Содержимое |
|--------|------------|
| **Строка 1** | Технические заголовки (английские, для бота) |
| **Строка 2** | Русские подписи колонок (для вас) |
| **Строка 3+** | Данные операций |

### Колонки

| Колонка | Русская подпись | Что это | Пример |
|---------|-----------------|---------|--------|
| A | Дата | Дата и время операции | `2026-01-30T14:25:00` |
| B | ID операции | Уникальный ID операции | `xyz789` |
| C | Артикул | Код товара | `PRD-001` |
| D | Название | Название | `Махорка СССР` |
| E | Количество | Количество списания | `5` |
| F | Было на складе | Остаток ДО | `60` |
| G | Стало на складе | Остаток ПОСЛЕ | `55` |
| H | Причина | Причина списания | `order` |
| I | Источник | `shop_order`, `owner_manual` | `shop_order` |
| J | ID актора | Telegram ID | `481890` |
| K | Имя актора | Username | `покупатель` |
| L | Примечание | Комментарий | `Авто-списание после счёта` |

### Причины списания (reason)

| Значение | Что значит |
|----------|------------|
| `order` | Продажа (автоматически при заказе) |
| `damage` | Порча товара |
| `gift` | Подарок |
| `correction` | Корректировка остатка |
| `other` | Другое |

### ⚠️ Важно про "Списание"

- **НЕ редактируйте вручную** — только бот пишет сюда
- **НЕ удаляйте строку 2** — это русские подписи для удобства
- При заказе товар списывается автоматически
- Ручное списание (порча, подарки) — через Owner Bot

## 🛒 Лист "Заказы" — Покупки клиентов

**Что это:** Все заказы от покупателей.

| Колонка | Что это | Пример |
|---------|---------|--------|
| **Заказ_ID** | Уникальный номер заказа | `ORD-260130-001` |
| **Дата/время** | Когда создан заказ | `2026-01-30 14:25` |
| **TG_user_id** | Telegram ID покупателя | `123456789` |
| **Телефон** | Телефон покупателя | `+79991234567` |
| **Статус** | Статус заказа | `Счет выставлен` |
| **Сумма_руб** | Сумма заказа в рублях | `5000` |
| **Доставка** | Способ доставки | `СДЭК` |
| **Город/ПВЗ** | Куда доставить | `Москва, ПВЗ Тверская 7` |
| **Позиции (SKU:qty)** | Что заказали | `PRD-001:5; PRD-002:3` |
| **Счет_PDF_файл** | Имя файла счёта | `ORD-260130-001.pdf` |

### Статусы заказа

| Статус | Что значит |
|--------|------------|
| `Счет выставлен` | Счёт отправлен, ждём оплату |
| `Оплачен` | Деньги получены |
| `Отправлен` | Посылка в пути |
| `Доставлен` | Покупатель получил |
| `Отменён` | Заказ отменён |

## 👥 Лист "Leads" — Клиенты (CRM)

**Что это:** База всех клиентов, которые писали боту.

| Колонка | Что это |
|---------|---------|
| **user_id** | Telegram ID клиента |
| **username** | Telegram username |
| **first_seen_at** | Когда впервые написал |
| **last_seen_at** | Когда последний раз был активен |
| **stage** | Этап воронки (см. ниже) |
| **orders_count** | Сколько заказов сделал |
| **lifetime_value** | На какую сумму купил всего |
| **phone** | Телефон (если указал) |
| **tags** | Метки (VIP, проблемный и т.д.) |
| **notes** | Ваши заметки о клиенте |

### Этапы воронки (stage)

| Этап | Что значит |
|------|------------|
| `new` | Только написал /start |
| `engaged` | Смотрел каталог |
| `cart` | Добавил что-то в корзину |
| `checkout` | Начал оформлять заказ |
| `customer` | Сделал первый заказ |
| `repeat` | Купил повторно |

## ⚙️ Лист "Настройки" — Параметры магазина

- Измените на свои реальные данные!

## ❓ Частые вопросы

### Как добавить новый товар?
→ Через Owner Bot: нажмите "📦 Приход товара" и следуйте инструкциям

### Как изменить цену товара?
→ Пока только вручную в таблице (колонка "Цена_руб")
→ Скоро будет через бот

### Почему "Дельта" не равна 0?
→ Где-то ошибка в данных. Проверьте:
1. Нет ли дублей операций в "Внесение" или "Списание"
2. Правильно ли указан SKU
3. Нет ли ручных правок в "Остаток_расчет"

### Как списать испорченный товар?
→ Через Owner Bot: найдите товар → "➖ Списать" → выберите причину "Порча"

### Как посмотреть историю товара?
→ Отфильтруйте лист "Внесение" или "Списание" по SKU товара
