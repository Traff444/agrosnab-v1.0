# Google Sheets Specification v1.1

> **Канонический контракт таблицы для системы магазина**
> Дата обновления: 2026-01-30
> Статус: **ACTIVE** (миграция завершена)

---

## Принципы

1. **SKU — неизменяемый ключ** (никогда не редактируется после создания)
2. **Числа — только числа** (формат отображения отдельно от значения)
3. **Даты — ISO 8601** (`2026-01-30T14:25:00`)
4. **Булевы — чекбоксы** (`TRUE`/`FALSE`, не "да"/"нет")
5. **Журналы — append-only** (только добавление, без редактирования)
6. **Двухстрочные заголовки в логах** (row 1 = английские для кода, row 2 = русские для пользователей)
7. **Русские названия колонок в Склад** (для совместимости с кодом)

---

## Совместимость с кодом

**Owner Bot** (`owner_bot/app/sheets.py`) проверяет точные имена колонок:
```python
REQUIRED_COLUMNS = ["SKU", "Наименование", "Цена_руб", "Остаток_расчет", "Фото_URL", "Активен"]
```

**Shop Bot** (`app/sheets.py`) использует гибкий поиск по подстрокам.

⚠️ **Важно:** Не переименовывать колонки на английские без обновления кода!

## 1. Лист "Склад" (мастер-данные товаров)

### Колонки (русские названия для совместимости с кодом)

| # | Колонка | Тип | Обязательно | Описание |
|---|---------|-----|-------------|----------|
| A | `SKU` | string | ✅ | Уникальный идентификатор (PRD-XXXXXX) |
| B | `Наименование` | string | ✅ | Название товара |
| C | `Описание_кратко` | string | | Краткое описание (для каталога) |
| D | `Описание_полное` | string | | Полное описание |
| E | `Цена_руб` | number | ✅ | Цена в рублях (только число, без ₽) |
| F | `Стартовый_остаток` | number | ✅ | Начальный остаток (при создании) |
| G | `Внесено_всего` | number | | Формула: сумма приходов из журнала |
| H | `Списано_всего` | number | | Формула: сумма списаний из журнала |
| I | `Остаток_расчет` | number | | Формула: F + G - H |
| J | `Остаток_по_логам` | number | | Формула для сверки (новая колонка) |
| K | `Дельта` | number | | Формула: I - J (должно быть 0) |
| L | `Поставщик_ID` | string | | Ссылка на Поставщик.Поставщик_ID |
| M | `Фото_URL` | string | | URL фото (Cloudinary или Google Drive) |
| N | `Активен` | boolean | ✅ | Чекбокс: TRUE/FALSE (не "да"/"нет") |
| O | `Теги` | string | | Теги через запятую |

### Формулы

> **Важно:** Google Sheets ru_RU использует `;` вместо `,` в формулах!

```
# G (Внесено_всего) - сумма приходов из колонки C (sku) и E (qty)
=IF(A2="";"";SUMIF(Внесение!C:C;A2;Внесение!E:E))

# H (Списано_всего) - сумма списаний из колонки C (sku) и E (qty)
=IF(A2="";"";SUMIF(Списание!C:C;A2;Списание!E:E))

# I (Остаток_расчет)
=IF(A2="";"";F2+G2-H2)

# J (Остаток_по_логам) - независимая проверка
=IF(A2="";"";F2 + SUMIF(Внесение!C:C;A2;Внесение!E:E) - SUMIF(Списание!C:C;A2;Списание!E:E))

# K (Дельта) - должно быть 0
=IF(A2="";"";I2-J2)
```

> **Примечание:** В логах Внесение/Списание `sku` находится в колонке C, `qty` в колонке E (после миграции v1.1).

### Валидация

- `sku`: уникальный, формат `PRD-XXXXXX`
- `price_rub`: число > 0
- `initial_stock`: число >= 0
- `stock_calculated`: число >= 0 (красный если < 0)
- `stock_delta`: должно быть 0 (красный если ≠ 0)
- `is_active`: только TRUE/FALSE

### Условное форматирование

| Условие | Цвет |
|---------|------|
| `stock_calculated < 5` | Жёлтый (критический остаток) |
| `stock_calculated <= 0` | Красный (нет в наличии) |
| `stock_delta ≠ 0` | Красный фон (рассинхрон!) |
| `is_active = FALSE` | Серый текст |

## 2. Лист "Внесение" (журнал приходов)

> **Append-only лог.** Бот только добавляет строки, никогда не редактирует.

### Структура строк

| Строка | Содержимое |
|--------|------------|
| **Row 1** | Английские заголовки (для кода) |
| **Row 2** | Русские описания (для пользователей, курсивом) |
| **Row 3+** | Данные |

### Колонки

| # | Заголовок (row 1) | Описание (row 2) | Тип | Описание |
|---|-------------------|------------------|-----|----------|
| A | `date` | Дата | datetime | ISO timestamp операции |
| B | `operation_id` | ID операции | string | UUID операции (для идемпотентности) |
| C | `sku` | Артикул | string | SKU товара |
| D | `name` | Название | string | Название (snapshot на момент операции) |
| E | `qty` | Количество | number | Количество (всегда > 0) |
| F | `stock_before` | Было на складе | number | Остаток ДО операции |
| G | `stock_after` | Стало на складе | number | Остаток ПОСЛЕ операции |
| H | `reason` | Причина | string | Причина: `intake`, `correction`, `return` |
| I | `source` | Источник | string | Источник: `owner_intake`, `owner_correction` |
| J | `actor_id` | ID актора | number | Telegram ID того, кто сделал |
| K | `actor_username` | Имя актора | string | Username |
| L | `note` | Примечание | string | Комментарий |

### Пример

```
Row 1: date | operation_id | sku | name | qty | stock_before | stock_after | reason | source | actor_id | actor_username | note
Row 2: Дата | ID операции | Артикул | Название | Количество | Было на складе | Стало на складе | Причина | Источник | ID актора | Имя актора | Примечание
Row 3: 2026-01-30T14:25:00 | abc123def456 | PRD-001 | Махорка СССР | 10 | 50 | 60 | intake | owner_intake | 123456789 | admin | Приход от поставщика
```

## 3. Лист "Списание" (журнал списаний)

> **Append-only лог.** Структура идентична "Внесение".

### Структура строк

| Строка | Содержимое |
|--------|------------|
| **Row 1** | Английские заголовки (для кода) |
| **Row 2** | Русские описания (для пользователей, курсивом) |
| **Row 3+** | Данные |

### Колонки

| # | Заголовок (row 1) | Описание (row 2) | Тип | Описание |
|---|-------------------|------------------|-----|----------|
| A | `date` | Дата | datetime | ISO timestamp |
| B | `operation_id` | ID операции | string | UUID операции |
| C | `sku` | Артикул | string | SKU товара |
| D | `name` | Название | string | Название (snapshot) |
| E | `qty` | Количество | number | Количество (всегда > 0) |
| F | `stock_before` | Было на складе | number | Остаток ДО |
| G | `stock_after` | Стало на складе | number | Остаток ПОСЛЕ |
| H | `reason` | Причина | string | Причина: `order`, `damage`, `gift`, `correction`, `other` |
| I | `source` | Источник | string | Источник: `shop_order`, `owner_manual`, `owner_correction` |
| J | `actor_id` | ID актора | number | Telegram ID |
| K | `actor_username` | Имя актора | string | Username |
| L | `note` | Примечание | string | Комментарий

### Причины списания (reason)

| Значение | Описание |
|----------|----------|
| `order` | Авто-списание при заказе |
| `damage` | Порча товара |
| `gift` | Подарок |
| `correction` | Корректировка остатка |
| `other` | Другое |
